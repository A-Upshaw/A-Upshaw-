## Projects

**[PortfolioOS](https://github.com/A-Upshaw/PortfolioOS)**: a personal investing platform on a modern data stack.
Daily Polygon.io prices load into Supabase (PostgreSQL), dbt builds staging models and six marts
(positions, P&L, sector exposure, benchmark vs. SPY), GitHub Actions runs it every weekday,
and a Streamlit dashboard with a Claude tool-use analyst sits on top.
Realized P&L uses weighted average cost, with FIFO lot relief.

**[AI Grant Discovery Pipeline](https://github.com/A-Upshaw/ai-grant-discovery-pipeline)**: my MSBA capstone, built for a client.
Notebooks use Claude or OpenAI to pull state small business funding programs into a local PostgreSQL database,
with checks that catch made-up award amounts and send only the unclear records to a person for review.
